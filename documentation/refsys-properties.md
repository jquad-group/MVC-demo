# Benutzerdefinierte RefSys Properties

| Property-Name                                     | Wert                                                         | Beschreibung                                                                                                                              |
|---------------------------------------------------|--------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------|
| ref-sys.circuitbreaker-enabled                    | ${CIRCUITBREAKER_ENABLED} (Wert aus der manifest.yml)        | Circuit-Breaker ein oder ausschalten                                                                                                      |
| ref-sys.iasd-enabled                              | ${IASD_ENABLED} (Wert aus der manifest.yml)                  | Laden der IASD Daten ein oder ausschalten                                                                                                 |
| ref-sys.initial-load.max-import-duration-in-ms    | 1200000                                                      | Maximaldauer eines Imports bevor ein anderer Import gestartet werden darf                                                                 |
| ref-sys.initial-load.parking-time-in-ms           | 120000                                                       | Update-Interval des StateDoc.stateTimestamp Feldes während ein Import läuft                                                               |
| ref-sys.initial-load.inventories-buffer-size      | 500                                                          | Buffer-/Batchgröße der gesammelten MovementDataInventories bevor diese in die mongoDB gespeichert werden                                  |
| ref-sys.initial-load.account-sum-days-buffer-size | 500                                                          | Buffer-/Batchgröße der gesammelten AccountSumDays bevor diese gemappt und in die mongoDB gespeichert werden                               |
| ref-sys.update-schema.schema-version              | 4 (aktueller Wert zum Zeitpunkt der Erstellung dieser Datei) | SchemaVersion im ProcessingService um, über das StateDoc.schemVersion Feld, festzustellen ob der Bestand ein aktuelles mongoDB Schema hat |
| ref-sys.mongodb.transaction-timeout-in-ms         | 30000                                                        | Maximale Dauer einer Transaktion bei der Delta-Verarbeitung                                                                               |
| ref-sys.mongodb.max-idle-time-in-ms               | 60000                                                        | Connection-Timeout für jeden mongoDB Aufruf                                                                                               |
| ref-sys.mongodb.min-pool-size                     | 5                                                            | Minimale Anzahl der pooled Connections für mongoDB                                                                                        |
| ref-sys.mongodb.max-pool-size                     | 200                                                          | Maximale Anzahl der pooled Connections für mongoDB                                                                                        |
| ref-sys.client.acds.base-path                     | ${ACDS_CLIENT_BASEPATH} (Wert aus der manifest.yml)          | Umgebungsspezifischer Basispfad für alle ACDS Schnittstellen                                                                              |
| ref-sys.client.acds.client-id                     | ${vcap.services.acds-creds.credentials.client-id}            | Umgebungsspezifische client-id für den ACDS Service im ApiGateway                                                                         |
| ref-sys.client.acds.client-secret                 | ${vcap.services.acds-creds.credentials.client-secret}        | Umgebungsspezifisches client-secret für den ACDS Service im ApiGateway                                                                    |
| ref-sys.client.acds.timeout-in-ms                 | 600000                                                       | Response-Timeout wenn ACDS aufgerufen wird (wird nur bei AccountSumDays verwendet)                                                        |
| ref-sys.client.acds.response-body-size-in-kb      | 6144                                                         | Maximale Response-Größe für ACDS Responses                                                                                                |
| ref-sys.client.basic-auth-admin.username          | ${vcap.services.basic-auth-admin-cred.credentials.username}  | Basic-Auth Benutzername                                                                                                                   |
| ref-sys.client.basic-auth-admin.password          | ${vcap.services.basic-auth-admin-cred.credentials.password}  | Basic-Auth Passwort                                                                                                                       |
